PhotoGallery

A web photo manager with album and tag organisation, built on Flask and SQLite.

Python Flask SQLite Jinja2

Overview

Upload images, organise them into albums with tags, and browse them in a gallery view. The interesting part is not the interface but the handling of files and metadata together: every operation has to keep the database and the filesystem in agreement.

Features

  • Validated upload — extension whitelisting for JPG, PNG, WebP and GIF.
  • Collision-free storage — files are renamed with a microsecond timestamp, while the original filename is preserved in the database.
  • Albums and tags — each photo carries a title, album and free-text tags.
  • Consistent deletes — removing a photo clears both the database record and the file on disk.

Data model

CREATE TABLE photos ( id INTEGER PRIMARY KEY AUTOINCREMENT, filename TEXT NOT NULL, -- stored name (timestamped) original_name TEXT NOT NULL, -- name as uploaded title TEXT NOT NULL, album TEXT NOT NULL DEFAULT 'General', tags TEXT NOT NULL DEFAULT '', size_bytes INTEGER NOT NULL, uploaded_at TEXT NOT NULL );

Indexed on uploaded_at and album — the two columns the gallery actually sorts and filters by.

What I learned

Storing the uploaded filename directly is a mistake that shows up quickly: two people upload photo.jpg and one overwrites the other. Separating the stored name from the display name solved it without losing the information the user cares about.
