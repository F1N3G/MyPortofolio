Grocery List

An editable grocery list with categories, saved lists and a dark/light theme — deployed and usable right now.

React 18 TypeScript Tailwind CSS Vite Vercel

Overview

A small, focused tool for building and reusing shopping lists. Items are added with a category, edited inline, checked off while shopping, and the whole list can be saved and reloaded later.

It is the smallest project here, and deliberately so. The goal was something genuinely finished and deployed rather than another half-built ambitious idea — open it and it works.

Features

  • Inline editing — click any item to edit it; Enter saves, Escape cancels.
  • Categories — Produce, Dairy, Bakery, Frozen, Household and more, shown as a tag on each item.
  • Check off items — mark things as bought as you go.
  • Search — filter the current list as you type.
  • Saved lists — timestamped, reloadable, individually deletable.
  • Copy list — copy everything to the clipboard for sharing.
  • Dark and light mode — toggled from the header.

What I learned

Scope discipline. Every feature I considered adding — prices, aisle sorting, shared lists — would have made it more impressive on paper and less likely to ever ship. Finishing something small taught me more about delivery than starting something large.
