CV Builder

A multi-section CV generator where most of the logic lives in the database.

PHP MySQL Stored procedures Triggers

Overview

Users register, fill in the sections of their CV — education, experience, skills, languages — and see a live preview as they go. What makes this project worth showing is not the interface but where the logic sits: much of it is implemented in SQL rather than PHP.

Features

  • Authentication and sessions — each user owns their own CV data.
  • Section CRUD — add, edit and remove entries across multiple CV sections.
  • Live preview — the CV updates as the form is filled.
  • Database-level logic — stored procedures, triggers and user-defined functions.

Database work

The parts I deliberately pushed into the database:

  • A trigger that creates an empty CV automatically when a user registers, so the application never has to handle a missing row.
  • A trigger that updates the modification timestamp on every change, without the application remembering to set it.
  • A function that counts how many sections a user has filled in, used to show completion progress.
  • Cascade cleanup on user deletion, so no orphaned rows survive.

What I learned

Putting invariants in the database rather than the application means they hold no matter which code path writes the data. The timestamp trigger is a small example, but it removed a bug I had already introduced twice by forgetting to update it manually in a new controller.
