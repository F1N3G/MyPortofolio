CulturalHub Android

A native Android client consuming the CulturalHub REST API.

Kotlin Jetpack Compose MVVM Retrofit Coroutines Coil
Work in progress. The core architecture — networking, repository, ViewModels and navigation — is in place. Booking, authentication and search are planned but not yet implemented.

Overview

This is the mobile half of CulturalHub. Rather than wrapping the web application in a WebView, it is a fully native client that talks to the Laravel backend over its REST API and renders everything in Jetpack Compose.

Building both sides of the same product taught me more than either would have alone: designing an API is a very different exercise when you are also the one consuming it.

Features

  • Event list — fetched from the CulturalHub API and rendered in Compose.
  • Event detail — navigable by event ID, passed as a typed navigation argument.
  • Explicit state handling — loading, success and error are modelled as distinct states.
  • Image loading — Coil, sharing the same OkHttp client as the API layer.

Architecture

Data flows in one direction, from the API through a repository into a ViewModel, which exposes it as observable state:

UI (Compose) → ViewModel → Repository → Retrofit → Laravel backend ↓ StateFlow

Each screen exposes its state as a sealed interface, which means the UI can only ever be in one of three defined states — and the compiler forces every branch to be handled:

sealed interface EventsUiState { data object Loading : EventsUiState data class Success(val events: List<Event>) : EventsUiState data class Error(val message: String) : EventsUiState }

The repository maps API DTOs into domain models, so nothing above it ever sees the shape of the network layer. If the backend response changes, the change stops at one file.

What I learned

Modelling UI state as a sealed interface rather than a set of booleans removed a whole class of bugs. With separate loading and error flags, it is easy to render an impossible combination. With a sealed interface, that state simply cannot be constructed.
