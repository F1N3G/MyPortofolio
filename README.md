## 🎯 About

This is my personal portfolio website built to showcase my programming projects, technical skills, and professional journey as a Computer Science student at Lucian Blaga University of Sibiu. The website features a clean, modern design with smooth animations and responsive layout.

## ✨ Features

- **Responsive Design**: Optimized for desktop, tablet, and mobile devices
- **Smooth Animations**: Implemented with AOS (Animate On Scroll) library
- **Interactive Navigation**: Fixed header with smooth scrolling between sections
- **Project Showcase**: Grid-based layout displaying GitHub repositories
- **Skills Section**: Overview of technical competencies
- **Contact Form**: Interactive form for visitor inquiries
- **Modern UI/UX**: Clean design with hover effects and transitions

## 🛠 Technologies Used

### Frontend
- **HTML5**: Semantic markup and structure
- **CSS3**: Custom styling with Flexbox and Grid
- **JavaScript**: Interactive functionality
- **AOS Library**: Scroll animations
- **Google Fonts**: Typography (Pacifico, Roboto)

### Development Tools
- **Visual Studio Code**: Primary IDE
- **Git/GitHub**: Version control and hosting
- **Chrome DevTools**: Debugging and testing

## 🚀 Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/GabrielaNec/MyPortofolio3.git
   ```

2. **Navigate to project directory**
   ```bash
   cd MyPortofolio3
   ```

3. **Open in browser**
   - Open `structure.html` in your preferred web browser
   - Or use a local server like Live Server extension in VS Code
