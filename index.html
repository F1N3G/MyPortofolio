Projects

A selection of what I've built. Full code on GitHub.

CulturalHub

Web platform for booking cultural events across 35+ Romanian venues. Seat-selection engine with multiple hall layouts, role-based access for admins, organizers and users, and a full admin panel with CRUD and reporting.

Laravel 12 · PHP 8.3 · MySQL

CulturalHub Android

Native Android client consuming the CulturalHub REST API. MVVM architecture with ViewModels driving a Jetpack Compose UI, Retrofit networking and Navigation Compose.

Kotlin · Jetpack Compose

Cultural Event Recommender

Hybrid recommendation engine combining weighted preference scoring over category, city and budget with TF-IDF and cosine similarity over event descriptions. Streamlit interface on a pandas pipeline.

Python · scikit-learn

Grocery List Live

Editable grocery list with categories, inline editing, search, saved lists and a dark/light theme. Deployed on Vercel — open it and try it.

React 18 · TypeScript · Tailwind

PhotoGallery

Web photo manager with upload validation, album and tag organisation, and deletes that clear both the database record and the file on disk. Indexed SQLite metadata schema.

Python · Flask · SQLite

CV Builder

Multi-section CV generator with authentication, sessions and live preview. Section tracking handled at database level through stored procedures, triggers and functions.

PHP · MySQL
